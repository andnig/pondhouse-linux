# Pondhouse Quattro Rollout

The final Pondhouse Omarchy v3 update is available. It provides the supported
migration to Pondhouse Linux, powered by Omarchy Quattro. Read and follow the
[employee upgrade instructions](../README.md), starting with the dry run.

Do not reset a checkout that reports update conflicts. Do not reboot after an
interrupted migration; use the exact resume command printed by the upgrader.
After migration, company updates come from signed Pondhouse packages rather than
this legacy Git checkout.
